# Rock Paper Scissors Game

A browser-based Rock Paper Scissors game built using HTML, CSS, and JavaScript. Play against the computer, track your score, and enjoy additional features like Auto Play and keyboard shortcuts.

## Live Demo

[Play Rock Paper Scissors](https://nikita-yadav-12.github.io/rock-paper-scissors-game/)

## Features

- **Interactive Gameplay:** Play Rock, Paper, or Scissors against the computer.
- **Random Computer Moves:** The computer randomly selects one of the three moves for each round.
- **Score Tracking:** Keeps track of wins, losses, and ties.
- **Persistent Score:** Uses Local Storage to save the score, so it remains available even after refreshing the page.
- **Auto Play:** Automatically plays the game at one-second intervals until stopped.
- **Reset Score:** Reset your score with a confirmation prompt to prevent accidental resets.
- **Keyboard Shortcuts:** Play the game and control Auto Play using keyboard keys.

## Keyboard Shortcuts

| Key | Action |
|---|---|
| `R` | Play Rock |
| `P` | Play Paper |
| `S` | Play Scissors |
| `A` | Toggle Auto Play |
| `Backspace` | Open Reset Score confirmation |

## Built With

- HTML5
- CSS3
- JavaScript
- Browser Local Storage
